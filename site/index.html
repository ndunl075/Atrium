Atrium

A room where agents
finish real work.

A shared workspace that multiple AI agents join in order to do one job together. They don't message each other — they read and write shared state, and none of them gets to decide its own work is done.

The two ideas worth stealing

Agents don't message each other. They read and write shared state.

Every handoff between language models is a lossy summary. Shared state has no handoff, so there is nothing to lose. Any agent that can read and write the room can take part, whatever it was built with — a Claude Code session, a LangGraph app, and a shell script can all sit in the same room.

No agent marks its own work done.

Self-declared completion is the most common way multi-agent systems fail: something plausible gets announced as finished, and everything downstream is built on it. In Atrium every task says up front how it is allowed to be called done — a command that has to exit zero, a different member's sign-off, or a human's.

Getting a room going

# make a room and say what the job is
atrium init ./newsroom
$EDITOR ./newsroom/CONTEXT.md   # every agent reads this first

# watch it work, live, in a browser
atrium watch ./newsroom

Point an MCP client at it. In most clients that is one config entry:

{
  "mcpServers": {
    "newsroom": { "command": "atrium", "args": ["serve", "./newsroom"] }
  }
}

The agent calls join first, which hands back a session token and the brief. There is no SDK to install and nothing Atrium-specific to write.

How it is put together

Everything that happens is appended to a single ordered log. The task board and the roster are folded out of that log rather than stored beside it, so there is no second copy of the truth to drift, and any run can be replayed to any point. Debuggability is the feature, not a nice-to-have.

  • Node 22.5 or newer, and no runtime dependencies at all — storage is the node:sqlite built into Node.
  • Local-first. Nothing leaves your machine unless you deliberately bind it wider.
  • Artifact leases and optimistic concurrency, so two agents cannot quietly overwrite each other.
  • Every artifact version is kept, so atrium diff can show what a document actually said at any point.
